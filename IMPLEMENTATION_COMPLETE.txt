================================================================================
  DATA FLOW
================================================================================

Promotion Process:
  1. Admin selects 1st Year source
  2. System loads 1st Year students
  3. Admin selects "2nd Year" target
  4. Admin clicks "Promote"
       ↓
  5. System Transaction Begins:
     ├─ Create StudentPromotion record (audit)
     ├─ Update Student.classId = 2nd Year
     ├─ Update Student.academicYearId = current
     └─ Commit or Rollback (atomic)
       ↓
  6. Student appears in 2nd Year ✓
  7. All related records preserved ✓

What Gets Updated:
  CHANGED:
  ├─ Student.classId (1st Year → 2nd Year)
  ├─ Student.academicYearId (current year)
  └─ StudentPromotion record (created)

  PRESERVED:
  ├─ Student.sectionId (same section)
  ├─ Student personal info (name, email, etc.)
  ├─ Fee records (linked by studentId)
  ├─ Attendance records
  ├─ Exam results
  └─ Book issues
